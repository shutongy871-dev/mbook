# MBook 八维文字识别手工测试

本轮验证：实际阅读采集 → 八维词典评分 → 本地保存 → 设置页展示与导出。
实际播放已接入八维：单维差0.2且欧式距离0.5筛选，空池交替放宽，再按余弦相似度选择。
识别分数看记录证据，匹配结果看实际筛选轮次；新窗口首选歌曲不同即切换，不设播放时长、分数增益、连续变化或趋势门槛。

## 1. 打开测试页

1. 在 Chrome 的 `chrome://extensions` 页面重新加载 MBook；尚未加载时，选择“加载已解压的扩展程序”，指定项目 `.output/chrome-mv3`。
2. 在插件设置中开启插件，将 AI 强度设为“关闭（纯本地词典）”，取消手动情绪锁定。初始八维阈值保留单维差0.2、距离0.5。
3. 在项目终端运行：

   ```sh
   python3 -m http.server 8765 --directory docs/reading-test
   ```

4. 在 Chrome 打开 <http://localhost:8765/>。不要直接双击HTML：当前内容脚本注入HTTP/HTTPS页面，不注入本地file页面。
5. 打开插件设置页的“阅读命中记录”，清空历史记录，便于统计。然后返回测试页。

测试页一次只展示一个用例，正文为三段、超过200字。说明和预期位于正文之外，便于正文抽取。
测试过程中不要修改窗口字数等参数。每次以记录中实际保存的原文为核对依据。

## 2. 每个用例怎么测

1. 从“无关键词”开始，阅读正文，保持测试页处于前台至少10秒。
2. 不要快速滚动。如果未出现专注状态，轻缓滚动、停留，再等10秒。保持至少80字正文可见。
3. 返回设置页，等待自动刷新或点击“刷新”。
4. 找到标题为“MBook 测试 N：…”的记录并展开，核对原文、八维分数和证据。
5. 切回测试页，查看该例预期结果；再点击“下一例”。切换用例会重新加载页面。

窗口顺序固定：**喜悦、悲伤、温柔、希望、恐惧、愤怒、神秘、庄严**。

同一正文重复三段是为了满足阅读采集要求；均值不因重复而增加。
实际窗口可能仅含一段或两段，所以命中次数不固定，不能一律按全文次数验收。
如果保存原文恰好截断“有点”“非常”等短语，应按截断后的输入判读，另找完整窗口验收该例。

## 4. 检查记录是否正确

- 原文和页面一致；页标题、URL、时间、窗口ID、章节信息可查看。
- 分数等于该维有效证据贡献之和÷有效命中次数；未有效命中的维度补0。
- 单条有效贡献=基础分×程度系数，最大1；否定证据贡献0且不计入有效次数。
- “当时歌曲”是分析发生时正在播放的歌；“选歌结果”是八维算法首选，记录写入后执行播放切换；加载失败会尝试其他候选。
- 画像版本应为 `emotion-8-mean-zero-v5`。
- 不含关键词的窗口也有记录；“命中窗口占比”只统计有至少一个正分维度的窗口，不是识别准确率。
- 一词多维时，总词条命中只计一次，各维证据分别展示。

## 5. 存储与导出测试

1. 点击“导出JSON”，确认下载文件有 `exportedAt` 和 `records`。
2. 每条记录应包含 `text`、`profile.vector`、证据、`thresholds`、`selectionMode`。
3. 阈值快照应为 `maxDifference:0.2`、`maxDistance:0.5`、`differenceStep:0.1`、`distanceStep:0.2`。
4. 新记录的 `selectionMode` 应为 `eight-dimensional`，并含 `matchingVector`、`analysisSource`、`selection`。
   `selection.attempts`含每轮阈值和通过数；首个非空轮次选余弦最高的候选，全零时轮次为空、保持当前或兜底。
5. 关闭设置页再打开，记录仍存在；重新加载扩展，再打开设置页，记录仍存在。
6. 最后导出备份后点击“清空记录”，确认记录列表和统计归零。

最近1000条、最多30天的限制在新记录写入时执行，不需要人工跑满验证。

## 6. 没有记录时检查

- 先确认已重新加载新构建，并刷新测试页面，以更新内容脚本。
- 页面前台停留至少3秒、正文可见至少80字、未快速滚动。
- 插件未关闭，没有手动情绪锁定。专注状态才触发分析，浏览状态不会记录。
- 切换到设置页后，阅读页不再前台，因此这段时间不会新增阅读记录。
- 同一窗口不会每秒重复记录；换用例或轻缓滚动到新的正文窗口再检查。
- 仍无记录时，在扩展的Service Worker控制台查找 `[reading-analysis] 记录失败`。

## 8. 八维界面与歌曲测试

1. Popup应同时显示喜悦、悲伤、温柔、希望、恐惧、愤怒、神秘、庄严八个分数。
2. 手动下拉应仅有自动理解和八个情绪；选择悲伤后分数为[0,0.8,0,0,0,0,0,0]，锁定10分钟。
3. 悬浮球仅显示“正在播放 · 歌曲名”或“已暂停 · 歌曲名”，播放图标为音符。
   Popup显示完整八维分数，不生成“愤怒”等汇总标签。
4. 用例1/11/13全零时保持当前歌；冷启动无当前歌时使用“稳定底噪”。
5. 手动暂停后继续阅读不得自动恢复；“下一首”须排除当前歌。
6. 升级会让外部旧画像失效，重新打标后才回到匹配池；曲库和原始反馈保留。
