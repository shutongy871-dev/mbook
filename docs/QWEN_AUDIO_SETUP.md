# Qwen 音乐听感八维识别

只保留一个共享模型，默认 `qwen3.8-omni-flash`，通过「文字识别」和「音乐识别」两个复选框分别开启用途。两者均输出固定八维 0～1 强度。

## 使用

1. 运行 `npm run build`，在 `chrome://extensions` 重新加载 `.output/chrome-mv3` 中的扩展，再打开设置。
2. 登录网易云网页版并同步曲库。
3. 在「常用设置 → 模型配置」填写接口地址、API Key 和模型名。旧版多个模型会合并为一个，优先保留已用于音乐识别的配置和原有用途开关。
   - 当前官方北京地域示例：`https://你的WorkspaceId.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`
   - 使用控制台为该模型提供的实际兼容地址；也接受完整 `/chat/completions` 地址。
   - Key 与该地址 / 工作空间 / 模型权限需匹配。
4. 勾选「音乐识别」；需要模型理解阅读内容时，再勾选「文字识别」。点击页面底部固定栏中的「保存设置」。
5. 「音乐画像」页只显示进度和批处理控制。逐首记录、分数依据、单首验证和重试在「记录与诊断 → 音乐识别诊断」中查看。识别按钮会先保存当前配置。

默认累计最多尝试 50 次，失败也计入。在「批处理设置」中提高上限并保存后可以继续；不会每日或重启后重置。只处理用户提交的队列，不会自动给后续同步的整个曲库付费识别。取消勾选「音乐识别」并保存可停止任务；已经发出的请求可能已经计费。已有画像继续可用。

## 文字识别

- 未勾选「文字识别」（默认）：使用本地词典及程度词、否定规则计算八维，不调用模型。
- 勾选「文字识别」且配置完整：直接采用模型返回的八维，既不先用词典切歌，也不把词典分数与模型结果加权。
- 模型请求在播放调度队列外异步运行，最多等待 25 秒；等待时维持当前播放。支持 Qwen 流式输出，忽略思考内容，只校验最终八维 JSON。
- 401、超时或格式失败：保留当前歌曲，在 Popup 和「记录与诊断 → 阅读识别记录」展示原因；不自动改为词典，也不把失败写成八维全零。
- 同一窗口合并并发请求并缓存；过期窗口、旧配置的结果不会覆盖当前阅读。手动暂停仍优先于识别。
- 文本模型只用于阅读文字；自动歌曲元数据打标不再借用文字模型产生额外调用。音乐模型由用户在音乐画像页启动。

## 口径与执行

- 八维顺序固定为：喜悦、悲伤、温柔、希望、恐惧、愤怒、神秘、庄严。
- 每维为独立的 0～1 强度，不是概率分布，不要求八项和为 1；提示词使用 0 / 0.25 / 0.5 / 0.75 / 1 的强度锚点。这些锚点是初版标尺，尚未人工校准。
- 原曲取前、中、后三个不重叠片段，每段最多 20 秒，合计最多 60 秒。短音频三等分；疑似试听截断（解码时长不足原曲 80%）直接失败。
- 音频在 Offscreen 中下载和离线解码，重采样为 16 kHz 单声道 PCM WAV，不播放采样，不干扰正在播放的 AudioContext。原始下载最大 32 MB，下载限时 30 秒，API 限时 120 秒。
- 一首歌一次流式请求；只解析 `delta.content`，忽略思考内容，严格校验完整结束标记、片段索引和八维数值。没有自动网络重试。
- 曲级分数 = 有效片段的 `SUM(维度分 × 片段秒数) / SUM(片段秒数)`。无法判断的片段为 `null`，不以 0 补齐。全部未知时保留原画像，记录为「无法判断」。
- 成功结果写入 `songProfiles.emotion_vector` 和 `audio_emotion`，直接进入现有候选池和八维匹配；元数据打标、播放特征回写不能覆盖听音画像。
- 画像成功不等于一定会播放：原有的人声、时长、音质、版权等候选过滤仍然生效。
- 同一歌曲、音频接口、模型、提示词 / 采样版本命中成功缓存，不重复调用。切换模型可重新识别，旧画像会保留至新画像成功。
- 任务和累计尝试量存于 IndexedDB。并发领取互斥，持久化 5 分钟租约。执行中断后不自动重发可能已计费的请求；失败或未知可在 60 秒后逐首重试。401 / 403 / 429 等认证、权限或配额错误会暂停后续队列，修正后点击识别按钮继续。
- 只保存画像、采样位置、听感依据、用量和固定错误说明；不保存原始音频或原始服务错误正文。曲库诊断导出不含 Key 或音频数据。

## 费用与效果验证

60 秒音频按官方 7 tokens/秒约为 420 音频输入 tokens；50 首最多约 21,000 音频输入 tokens，另计提示词和输出（含模型思考）。价格以工作空间对应地域、模型和账单为准。这里的累计尝试不是成功数，也不是实际计费请求数；下载失败同样占一次尝试。

分段采样不能保证覆盖整首的所有变化。模型输出是听感估计；模型自评置信度不是准确率。与文本维度、范围一致并不代表两者强度已完成听感标定。

## 工程验证

- `npm test`：采样位置 / WAV 编码、流式协议、八维校验、未知处理、队列互斥、配额、缓存和画像覆盖保护。
- `npm run typecheck` / `npm run build`：类型与生产包检查。
- `node scripts/browser-qwen-audio.mjs`：独立浏览器中的生产扩展界面与消息链路，真实本地音乐解码；Qwen 响应及外部网络使用测试夹具，不调用真实服务。可通过 `MBOOK_CHROME` 指定 Chromium 可执行路径。报告输出 `.artifacts/qwen-audio/results.json`。
- `node scripts/browser-model-settings.mjs`：旧配置迁移、窄屏设置界面、模型复用、真实阅读页面的词典 / 模型切换及失败记录。API 为模拟响应，报告输出 `.artifacts/model-settings/results.json`。

尚未配置真实 Key 时，以上工程验证不能证明 Qwen 的实际音乐情绪识别质量。需要用自己的 Key 完成单首验证并试听校准。

浏览器测试在当前沙箱中退出时会尝试写入工作区外的 Chrome 系统目录，可能被拦截并返回退出码 1；断言是否通过以对应报告为准。
